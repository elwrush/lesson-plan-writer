# In Thai {#slide-thai data-auto-animate="true"}

::: {.auto-animate data-id="thai-pattern"}
O---O---O---[**STRONG**]{.box}
:::

::: {.auto-animate data-id="rule"}
Every word: [**last part always strong**]{.box}
:::

::: {.auto-animate data-id="example-thai"}
คอมพิว[**เตอร์**]{.box} (computer) -- weak weak **STRONG**
:::

::: notes
Thai fixed stress: the last syllable is always strong. Students can feel this with the Thai example.
:::

# In English {#slide-english data-auto-animate="true"}

::: {.auto-animate data-id="thai-pattern"}
[**O**]{.box}---o---[**O**]{.box}---o
:::

::: {.auto-animate data-id="rule"}
Every word: [**stress can be anywhere**]{.box}
:::

::: {.auto-animate data-id="example-thai"}
[**TEACH**]{.box}-er  |  [**ANS**]{.box}-wer
:::

::: notes
English is different. The strong part can move. You have to learn each word.
:::

# Stress Markers {#slide-bc-method}

We use the **O o** (big circle / small circle) method:

- **O** = strong syllable (big circle)
- **o** = weak syllable (small circle)

[**teacher** -> O o]{.box}
[**boring** -> O o]{.box}
[**understand** -> o o O]{.box}

::: notes
Demo on board first. Then point to Exercise C on worksheet.
:::

# Exercise C: Mark the Stress {#slide-controlled data-timer="420"}

On your worksheet Exercise C, mark the stress for each sentence.

1. My teacher gave us a boring lesson.
2. I don't understand the answer.
3. Another student told me a story.
4. My favourite subject is history.
5. Please explain the problem carefully.

Circle every word with more than one syllable. Mark **O** for strong, **o** for weak.

::: notes
7 minutes. Students work individually. Teacher circulates. Board answers for self-correction.
:::

# Exercise E: Write Your Own Sentences {#slide-free-practice data-timer="420"}

On your worksheet Exercise E, write 3 sentences.

1. Write about a school subject you like or don't like.
2. Write about something a teacher said to you yesterday.
3. Write about a hobby you have.

**Then:** Circle every word with more than one syllable. Mark the stress using **O o**.

::: notes
7 minutes. Students write individually. After writing, they mark their own stress patterns.
:::

# Read to Your Partner {#slide-pair-practice data-timer="180"}

**Listen:** Did your partner put the stress in the right place?

::: notes

:::
