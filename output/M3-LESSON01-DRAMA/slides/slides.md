# What is a Table Read? {#slide-pre-watch}

<!-- PEDAGOGICAL INTENT: Students SEE the viewing task scaffolded via two fragment reveals — definition then focus question -->
<!-- WHY THIS FEATURE: fragments prevent cognitive overload by layering context before setting the task -->
<!-- COGNITIVE PRINCIPLE: Segmenting (Mayer) — break instruction into two digestible parts -->

[Actors sit around a table, read the script aloud -- no costumes, no sets, no cameras.]{.fragment .white-reveal}

[WATCH THEIR VOICES. How do these actors show emotion and character using ONLY their voice?]{.fragment .white-reveal}

::: notes
Ask: "Has anyone seen a table read before?" Elicit or explain. Set the task: "We're going to watch the SAME scene twice. First, the table read — voices only. Watch their VOICES. How do they show emotion without body language or camera work?"
:::

# The Secret {#slide-principle}

[getting into a role]{.box}

[He's not being "Aaron Paul" -- he's being Jesse. The character frees him.]{.fragment .answer-reveal}

::: notes
"Why does Aaron Paul's table read work, even without acting? He's not being 'Aaron Paul' — he's being Jesse. The character frees him from self-consciousness. When you're a character, you're not worried about your own mistakes. You're worried about what the character wants."
:::
