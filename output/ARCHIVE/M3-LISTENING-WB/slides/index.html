Useful Phrases

Persuasion Phrases

Use these phrases to persuade someone:

  • Have you ever considered + -ing (suggest an idea)
  • You might not realize this, but (introduce a surprising fact)
  • I know someone (give a personal example)
  • it really helped + object (share a positive outcome)
  • Perhaps you could + infinitive (make a polite suggestion)
  • Sorry, I'm not convinced (express doubt politely)
  • OK, you've persuaded me (show agreement)

Want to go further? Write one original sentence for each phrase.
