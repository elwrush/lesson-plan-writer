## Per-Slide Design

| Slide ID | Intent | Mechanism |
|----------|--------|-----------|
| slide-splash | Topic image primes editing theme non-verbally | Full-bleed bg image with no text. No shield needed. |
| slide-title | Logo, topic, badge, strap "Good writing gets better" + CTA "Let's Edit" | text-shield on all text. Crimson CTA signals active editing. |
| slide-objective | 3 outcomes: self-edit my draft, peer-verify with partner, produce final version | Yellow numbers + white text. No fragments. |
| slide-lead-in | Before/After paragraph comparison shows why editing matters | Two bordered boxes side by side. Rough vs polished. Teacher elicits differences. |
| slide-transition-review | Red bg signals quick recap | Heading only. No notes. |
| slide-refresher | 5 focus areas in compact summary (teal) | One concept per minute. Rapid-fire format. |
| slide-transition-edit | Red bg signals station phase | Heading only. No notes. |
| slide-stations | ALL 5 stations visible — the control panel for the carousel (teal) | Each station has name + focus + task + verify line. Compact stacked layout. Stays on screen while teacher circulates. |
| slide-transition-polish | Red bg signals final phase | Heading only. No notes. |
| slide-writing-task | Checklist + 14-min timer | Side-by-side: checklist on left, timer controls on bottom. |
| slide-summary | 3 checkmarks matching objectives | Structural bookend. |
