## Key Design Decisions

1. **No icons** — per AGENTS.md, all `<i class="fa-solid ...">` elements removed from every slide type
2. **No auto-downloads** — all backgrounds are solid colors (no Pixabay API calls)
3. **Splice approach** — write all `<section>` elements to `C:\Users\elwru\AppData\Local\Temp\kilo\slides_sections.html`, then Python script splices them into the template copy
4. **Fragment classes** — use `answer-correct` and `answer-incorrect` only; never `highlight-green`/`highlight-red`
5. **Auto-animate** — use `data-auto-animate-id` on every auto-animate slide; only for the PET scale zoom-in slide pair (Slide 3a/3b); all other pedagogical content uses simple sibling slides
6. **Transition slides** — heading only, no `<p>` elements
7. **B1 language** — direct "you" imperatives, ≤15 words per sentence, no passive voice, vocabulary ceiling (no "identify", "distinguish", etc.)
8. **Stable slide IDs** — every `<section>` gets an `id` attribute following convention: `slide-title`, `slide-objective`, `slide-lead-in`, `slide-pet-scale`, `slide-test1-items`, `slide-test1-answers`, `slide-test2-items`, `slide-test2-answers`, `slide-transition-learn`, `slide-teach-sentence-def`, `slide-teach-fragments`, `slide-teach-commands`, `slide-transition-cap-rules`, `slide-cap-rules-1-3`, `slide-cap-rules-4-6`, `slide-p2b-task`, `slide-p2b-answers-1-3`, `slide-p2b-answers-4-6`, `slide-p2b-answers-7-9`, `slide-p2b-answers-10-11`, `slide-p2b-answers-12-13`, `slide-p7-task`, `slide-p7-answers-1-6`, `slide-p7-answers-7-12`, `slide-p7-answers-13-18`, `slide-summary`, `slide-end`
9. **Speaker notes** — every slide except transitions and end gets `<aside class="notes">` with stage aim, timing, interaction pattern, and full procedure text
