# Plan: build-a-monolog Skill

## Overview

Create a project-level skill (`build-a-monolog`) that generates an audio monolog from source text using Inworld TTS (voice design or cloning), with optional text modification via DeepSeek V4 Flash and audio post-processing via FFmpeg.

A lightweight Kilo command (`/build-a-monolog`) triggers the skill.

## Workflow (5 Steps)

### Step 1 — Source Text

Agent asks the user:
- Provide absolute path to a monolog file (`.md`, `.txt`, `.pdf`, `.m4a`, `.mp3`), OR
- Ask agent to generate the monolog (if so, ask for CEFR level and topic)

**If audio file** (`.m4a`, `.mp3`): transcribe via AssemblyAI pipeline first, then proceed.

**If PDF**: extract text using `pymupdf` (`fitz.open(path)` → `page.get_text()`).

**If user requests generation**: use the agent's own LLM (or DeepSeek) to generate a monolog at the specified CEFR level and topic, then show for approval.

### Step 2 — Voice Source

Agent reads `cloned-voices/readme.md` to discover available cloned voices. Agent asks: "Use an existing cloned voice, clone a new voice from audio, or create a bespoke voice?"

**Existing clone path:**
- Show the user the list of voices from `cloned-voices/readme.md`
- User picks one → use its stored Inworld voice ID
- Readme format (example, to be populated by the skill):
  ```
  # Cloned Voices Library
  
  ## northern-british-male
  - Voice ID: default--rf1eqxo3dlqcm8fna-a2g__design-voice-f1ab8830
  - Age: mid-40s, Gender: male, Region: northern England
  - Tone: lonely, melancholic
  - Created: 2026-05-27
  
  ## north-london-teen
  - Voice ID: default--rf1eqxo3dlqcm8fna-a2g__design-voice-da1fe46f
  - Age: mid-teens, Gender: female, Region: north London
  - Tone: hesitant, lonely
  - Created: 2026-05-27
  ```

**Clone from audio path:**
- Ask for path to reference audio file (`.m4a`, `.mp3`, `.wav`)
- Upload to Inworld Voice Cloning API (`POST /voices/v1/voices:clone`)
- Save resulting voice ID + metadata to `cloned-voices/readme.md`

### Step 3 — Text Preparation

The agent modifies the monolog text **directly** (no separate API call — the agent is powered by DeepSeek V4 Pro). **Always** add ellipsis and prosodical markers following these rules:

**STEERING TAGS** (Inworld TTS-2 format):
Place a steering tag in `[brackets]` before the text it applies to. The tag applies forward until the next tag.
- Examples: `[speak sadly, with deliberate pauses]` `[say excitedly, very fast]` `[very quiet, almost a whisper]` `[calm and steady, with warm tone and measured pace]`
- Combine dimensions: `[sad, quiet, with long pauses]` outperforms just `[sad]`.

**PAUSES & PACING:**
- Use `...` for short pauses/hesitations within a sentence
- Use `......` for longer pauses or thought breaks
- Use periods and punctuation naturally — the model respects them
- CAPITALIZE key words for stress: "I told you NOT to do that."

**NON-VERBAL MARKERS** (inline, exactly where they occur):
- `[sigh]` — before a resigned or weary line
- `[laugh]` — after a humorous line
- `[breathe]` — for dramatic inhalation
- `[cough]`, `[clear throat]`, `[yawn]` — where contextually appropriate

**PROSODY** (only if user requested demographic-matched text):
- Modify vocabulary and phrasing to match how the demographic would naturally speak
- Preserve ALL original meaning and key content
- Never add new ideas or remove required points
- For regional accents: use words typical of that region (e.g., British: "brilliant", "proper", "spot on")

**RULES:**
- Do NOT over-tag — one steering tag applies forward until the next
- Place non-verbals where a human would naturally do them
- Never change the meaning or remove content
- Keep steering descriptions as natural language prose, not keywords

Agent then shows the modified text to the user **for approval** before proceeding.

Then agent shows the modified text to the user **for approval** before proceeding.

### Step 4 — Generate Audio

Agent calls Inworld TTS API with:
- `voice_id` (from Step 2)
- Modified text (from Step 3)
- `model_id: "inworld-tts-2"`
- `audio_config: {"audio_encoding": "MP3", "sample_rate_hertz": 24000}`

Saves output to `output/{subfolder}/monolog-{timestamp}.mp3`.

### Step 5 — Post-Processing

Agent asks: "Would you like to modify the audio? Options: rate, pitch, tone, silences."

**FFmpeg operations:**
- **Rate (speed)**: `ffmpeg -i input.mp3 -filter:a "atempo=0.9" output.mp3` (0.5-2.0 range)
- **Pitch**: `ffmpeg -i input.mp3 -filter:a "asetrate=44100*0.8,atempo=1.0" output.mp3` (lower pitch)
- **Silence truncation**: `ffmpeg -i input.mp3 -af "silenceremove=start_periods=1:start_duration=0.5:start_threshold=-30dB" output.mp3`
- **Volume**: `ffmpeg -i input.mp3 -filter:a "volume=0.8" output.mp3`
- **Bass/treble**: `ffmpeg -i input.mp3 -af "equalizer=f=100:t=q:w=1:g=5,equalizer=f=10000:t=q:w=1:g=-3" output.mp3`

Agent applies modifications iteratively (user can request multiple rounds).

## Inworld Voice Design Best Practices (from docs.inworld.ai, May 2026)

### Voice Description Structure

Per Inworld's official docs, structure descriptions in this order:
> *Distinctive Qualities → Gender → Language/Accent → Age → Tone → Delivery Style → Pacing → Additional Qualities → Audio Quality*

Example: *"A soothing, calming female voice with soft American accent, 30-45 years old. Gentle, flowing delivery with natural pauses and smooth transitions. Warm, peaceful tone that creates relaxation without sounding robotic. Perfect broadcast quality audio."*

### Voice Description Rules

- **Length**: 30-250 characters (Portal) or 30-1000 (API). Keep concise but specific.
- **Regional accents**: "specify the city or region" — "Yorkshire accent", not "northern England accent"
- **Age**: Use ranges ("mid-20s to early 30s"). For children: exact ages ("8-10 years old") plus "natural, age-appropriate". For elderly: age range + texture ("gravelly", "weathered") + pacing ("slower, deliberate")
- **Vocal texture**: Place in the MIDDLE of description, never at end. Use "slight", "subtle", "natural" modifiers
- **Audio quality**: End with "Perfect broadcast quality audio." — prevents texture descriptors from being misinterpreted as audio degradation
- **Avoid conflicting descriptors**: Can't have "fast-paced" with "slow, deliberate"
- **Multiple generations**: Each run produces slightly different results. For less common voices (children, elderly, specific regional accents), may need 2-3 attempts

### Script Best Practices

- **Match script to voice**: For accented voices, use words typical of that accent (British: "brilliant", "proper", "spot on")
- **Script length**: 5-15 seconds of audio (50-200 characters in English)
- **Match language**: Script must be in the same language as the desired voice

### Steering Tags (TTS-2) — Inworld Realtime TTS-2

Format: `[instruction] Text to speak.` Tag applies forward until next tag or end.

| Category | Examples |
|---|---|
| **Emotion** | `[speak excitedly]`, `[sound concerned]`, `[sound terrified]`, `[say sadly]` |
| **Pacing** | `[articulate clearly, with deliberate pauses]`, `[very fast, urgent]`, `[very slow, measured]` |
| **Volume/Pitch** | `[very quiet, almost a whisper]`, `[say in a low tone, gravelly]`, `[say in a high pitch, bright and cheerful]` |
| **Vocal style** | `[whisper in a hushed style]`, `[give a nasal quality, slightly annoyed]` |
| **Combined** | `[say sadly with deliberate pauses in a low voice and hushed style]` |
| **Non-verbals** (inline) | `[laugh]`, `[sigh]`, `[breathe]`, `[clear throat]`, `[cough]`, `[yawn]` |

**Writing effective directions:**
- Write stage directions, not keywords. "Say this like you're apologizing to someone you care about" beats "apologetic"
- Combine at least two dimensions. "Sad" is vague. "Sad, quiet, with long pauses" is a read
- Capitalization for stress: "I told you NOT to do that."
- Punctuation for pacing: ellipses (`...`) create lingering pauses
- Don't over-tag — one tag carries forward until the next
- Place non-verbals where a human would do them (sigh before resigned sentence, laugh after punchline)

## FFmpeg Audio Post-Processing Reference

### Pitch Shifting

| Method | Command | Notes |
|--------|---------|-------|
| **Rubberband** (best quality) | `ffmpeg -i in.mp3 -af "rubberband=pitch=1.0594630943" out.mp3` | 1 semitone up. Formula: 2^(x/12). Preserves formants |
| **Asetrate + atempo** (simpler) | `ffmpeg -i in.wav -af "asetrate=44100*1.2,aresample=44100" out.wav` | Changes both pitch and speed. Use with atempo to compensate |
| **Rubberband with tempo** | `ffmpeg -i in.mp3 -af "rubberband=tempo=1.0:pitch=1.2" out.mp3` | Pitch 20% higher, tempo unchanged |

### Tempo/Speed (without pitch change)

`ffmpeg -i in.mp3 -af "atempo=0.8" out.mp3` — 0.5 to 2.0 range. Chain multiples for >2×: `atempo=2.0,atempo=1.5`

### Silence Processing

| Effect | Command |
|--------|---------|
| **Remove leading silence** | `-af "silenceremove=start_periods=1:start_duration=0.5:start_threshold=-40dB"` |
| **Remove leading + trailing** | `-af "silenceremove=start_periods=1:start_duration=0.5:start_threshold=-40dB,stop_periods=1:stop_duration=0.5:stop_threshold=-40dB"` |
| **Detect silence positions** | `-af "silencedetect=noise=-30dB:d=1.0" -f null -` (prints metadata) |

### Volume & EQ

| Effect | Command |
|--------|---------|
| **Volume** | `-af "volume=0.8"` (0.0-1.0 range) or `volume=+3dB` |
| **Normalization** | `-af "loudnorm=I=-16:TP=-1.5:LRA=11"` |
| **Highpass** | `-af "highpass=f=200"` (removes rumble below 200Hz) |
| **Lowpass** | `-af "lowpass=f=3000"` (removes hiss above 3kHz) |
| **Equalizer** | `-af "equalizer=f=100:t=q:w=1:g=5"` (boost 100Hz by 5dB) |
| **Compand (dynamic range)** | `-af "compand=attacks=0:points=-80/-105|-62/-80|-15/-15|0/-12|20/-12"` |

### Fades

| Effect | Command |
|--------|---------|
| **Fade in** | `-af "afade=t=in:d=2"` (2-second fade in) |
| **Fade out** | `-af "afade=t=out:st=30:d=3"` (3-second fade out starting at 30s) |

### Combined Pipeline Example

```powershell
ffmpeg -i "input.mp3" -af "highpass=f=200,lowpass=f=3000,loudnorm=I=-16:TP=-1.5:LRA=11,atempo=0.9,silenceremove=start_periods=1:start_duration=0.5:start_threshold=-40dB" "output.mp3"
```

This: removes rumble + hiss → normalizes volume → slows 10% → trims leading silence.

## Inworld API Patterns (from previous testing)

### Voice Design (bespoke)
```python
# POST /voices/v1/voices:design
design_prompt = "A male voice, mid-40s, from northern England..."
r = requests.post("https://api.inworld.ai/voices/v1/voices:design", ...)
preview_id = r.json()["previewVoices"][0]["voiceId"]

# POST /voices/v1/voices/{preview_id}:publish
r2 = requests.post(f"https://api.inworld.ai/voices/v1/voices/{preview_id}:publish", ...)
saved_id = r2.json()["voiceId"]
```

### Voice Cloning
```python
# POST /voices/v1/voices:clone
with open(ref_audio_path, "rb") as f:
    files = {"audio_bytes": ("ref.m4a", f, "audio/mp4")}
    r = requests.post("https://api.inworld.ai/voices/v1/voices:clone",
        headers={"Authorization": f"Basic {api_key}"},
        data={"voice_name": "cloned-voice"},
        files=files)
voice_id = r.json()["voiceId"]
```

### TTS Generation
```python
# POST /tts/v1/voice
r = requests.post("https://api.inworld.ai/tts/v1/voice",
    headers={"Authorization": f"Basic {api_key}", "Content-Type": "application/json"},
    json={
        "text": modified_text,
        "voice_id": voice_id,
        "model_id": "inworld-tts-2",
        "audio_config": {"audio_encoding": "MP3", "sample_rate_hertz": 24000}
    })
audio_bytes = base64.b64decode(r.json()["audioContent"])
```
