## Key Design Decisions

### Lead-in auto-animate
- 2 consecutive `<section data-auto-animate>` elements with matching `data-auto-animate-id="lead-in-errors"`
- Slide #3: 6 sentences with `<span data-id="e1" style="border-bottom: 2px solid transparent;">...</span>` wrapping the error word
- Slide #4: Same sentences, `border-bottom: 2px solid white;` on the corrected words — auto-animate animates the border color change
- `data-background="#1a1a2e"` on both (dark navy, not teal — this isn't pedagogical, it's lead-in)

### Diagnostic test (Slide #5)
- All 8 items in an `<ol>` visible on entry — NO fragments
- Dark `#1a1a2e` background with pencil icon
- `<aside class="notes">` with monitoring instructions

### Grammar rules (Slides #7, #8)
- Use `fa-book-open` icon with `pedagogical-icon` CSS class
- Teal `#1a6b5a` background, `class="pedagogical"`
- Rule labels: `<u><strong>Rule N:</strong> description</u>`
- Examples in `<em>` with key grammar words in `<span style="color:#ffdd00;">`
- Slide #7: Rules 1-3, Slide #8: Rules 4-5 + recap table of all 5

### Answer tables (Slides #11-13)
- Practice 3A (11 short fill-in-the-blank items): 
  - #11: items 1-6 (6 rows, short items)
  - #12: items 7-11 (5 rows, short items)
- Practice 3B (6 editing errors):
  - #13: all 6 errors in Original→Correction table (6 rows, medium items)
- All use `fragment answer-correct` with `style="color:#ffdd00;"` for yellow answer text
- No `highlight-green`/`highlight-red` — using `answer-correct` / bare `fragment` only

### Icons
- Objective: `fa-seedling objective-icon`
- Lead-in: `fa-eye` (inherit color)
- Diagnostic test: `fa-pencil` (inherit color, dark bg)
- Transition: `fa-forward transition-icon`
- Teach: `fa-book-open pedagogical-icon`
- Task: `fa-pencil`
- Summary: `fa-flag-checkered`
- End: `fa-star`
