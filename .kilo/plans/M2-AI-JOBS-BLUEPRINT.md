### Per-Slide Design
| Slide ID | Intent | Feature | Principle | Mechanism | Template Ref |
|----------|--------|---------|-----------|-----------|--------------|
| slide-splash | Student sees a full-screen robot image with no text — primes topic visually before any information | Static image slide | Coherence — no text to distract from the visual | Image fills viewport edge-to-edge; no content at all forces silence and looking | Title splash pattern |
| slide-title | Student sees topic + level + lesson type | Static title layout | Signaling — h2 announces topic, CEFR badge signals level, CTA hints at activity | Logo at top, h2 with B1 badge in heading, strap line below, crimson CTA at bottom; center-justified | Type 1: Title Slide |
| slide-objective | Student sees 3 "I can" statements to understand what they will achieve | Static bullet list | Segmenting — three separate outcomes preview the lesson structure | All 3 bullets visible on entry (no fragments); teacher reads and connects to topic | Type 2: Objective Slide |
| slide-lead-in | Student sees a question about AI and jobs to activate schema | Static question | Pre-training — activates prior knowledge before input | One discussion question on dark background, no image; teacher elicits ideas | Type 4: Lead-In |

None — this lesson uses no auto-animate. Vocab uses fragments, not auto-animate. No strategy demonstrations with progressive build-up.

### Notes
- No TTS audio generation needed (would require Inworld API voice design which is external). Vocab slides show word without audio.
- No timer plugin on any slide (timers not needed for this lesson structure)
- No auto-animate pairs — vocab uses fragments instead
- The YouTube video is embedded on the Part 1 task slide only; Parts 2 and 3 use text-only task slides
- Answer slides use answer-list flex layout (not table.answer-table)
