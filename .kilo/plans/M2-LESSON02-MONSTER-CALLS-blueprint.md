# Lesson Plan Blueprint: Scene Creation -- A Monster Calls

**Follow-up to:** M2-LESSON01-MONSTER-CALLS  
**CEFR:** A2/B1  
**Shape:** F (Productive Skills)  
**Duration:** 46 minutes

---

## Stages

| Stage | Name | Time | Aim |
|-------|------|------|-----|
| 1 | Lead-in -- Recall Characters | 5 min | Reactivate memory of M2-LESSON01 characters and their voices |
| 2 | Define the Problem | 5 min | Different characters see the same event differently |
| 3 | Model Analysis | 5 min | Analyse a model scene from another perspective (Lily) |
| 4 | Group Formation | 3 min | Form groups, assign character/scene |
| 5 | Write | 20 min | Write a scene from one character's POV |
| 6 | Script Check + Rehearse | 5 min | Peer review, rehearse aloud |
| 7 | Wrap-up | 3 min | Preview performance, one-word reflection |

## Handout

Same handout structure as M3-LESSON02 but adapted for A Monster Calls characters and A2/B1 language:

- Scene Structure Guide (Opening → Middle → Resolution)
- Word Count Target (simpler: ~10 lines per character)
- Teacher Demo Model (Lily's POV of the bullying)
- Script Format Guide
- Group assignments (5 groups, each a different character's perspective on the bullying)
