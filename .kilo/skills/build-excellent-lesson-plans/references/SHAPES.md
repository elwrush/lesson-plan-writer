# Lesson Plan Shapes

Shape templates are stored at `knowledge-base/lesson plan shapes/json/shape-{letter}.json`.

| Shape | Name |
|-------|------|
| A | Text-based Presentation of Language |
| B | Language Practice |
| C | Test-Teach-Test |
| D | Situational Presentation (PPP) |
| E | Receptive Skills (Traditional) |
| F | Productive Skills (Traditional) |
| G | Task-Based Learning/TBL |

Each shape JSON contains stage structure, `main_aim_format`, and `pedagogical_justification`.
