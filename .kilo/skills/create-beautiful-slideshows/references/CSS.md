| Class | Usage | Effect |
|-------|-------|--------|
| `.title-logo` | `![](logo.png){.title-logo}` | Max-height 108px, centered, block |
| `.shield` | `::: {.shield}` | Dark semi-transparent overlay. **Image backgrounds only.** |
| `.cta-text` | `[text]{.cta-text}` | Yellow bold |
| `.cefr-badge` | `[B2]{.cefr-badge}` | Blue badge inline with title |
| `.answer-reveal` | `::: {.fragment .answer-reveal}` | Yellow bold on reveal. **Answers only.** |
| `.iframe-container` | Generated by `youtube-embed.lua` | Responsive 16:9 YouTube iframe |

# Design Rules

1. **All slides horizontal** — `--slide-level=1` only
2. **No `---` separators** — use only `# ` headings for slide breaks
3. **Every content slide has `::: notes`** with timing and interaction
4. **Speaker notes format:** `Time: N min. Interaction: T-Ss.` followed by instructions
5. **Yellow headers** — `h1` is `#ffdd00` at 1.3em
6. **Text shields on image backgrounds ONLY** — never on solid colors
7. **Fragment answers** — use `::: {.fragment .answer-reveal}`
8. **Transitions** — red background `#c0392b`
9. **Auto-animate pairs** — both slides share the same `data-auto-animate-id`, exactly 2 times
